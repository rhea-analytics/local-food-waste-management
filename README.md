Local Food Wastage Management System

Overview
A Streamlit-based application developed to reduce food wastage by connecting food providers with receivers. The system allows providers to list surplus food and enables receivers to claim available food efficiently.

Technologies Used
- Python
- SQL (SQLite)
- Streamlit
- Pandas
- Plotly

Features
- Food listing management
- Receiver and provider management
- CRUD operations
- SQL-based analysis
- Interactive dashboards and visualizations
- Food filtering by location, provider, and food type

Datasets
- Providers Dataset
- Receivers Dataset
- Food Listings Dataset
- Claims Dataset

Project Outcome
This project helps reduce food waste, improve food distribution, and demonstrates the use of Python, SQL, Streamlit, and Data Analysis in solving a real-world problem.
